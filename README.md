## Web local

Requiere Python 3.10 o superior; no necesita instalar dependencias.

```sh
cd 06_Web
python server.py
```

Consulta [las instrucciones completas](06_Web/LEEME.md). El servidor es un prototipo local: no expone pagos, no envía correos y no debe publicarse directamente en Internet. La base SQLite de contactos queda excluida de Git.
